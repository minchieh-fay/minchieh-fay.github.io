先看一个家庭场景。

一个孩子除了学习通用知识，还被训练出固定的放学流程：回家先做半小时数学，休息十分钟，再做四十分钟语文。几天后，孩子被送到别人家寄养。寄养家庭要求他先吃饭，饭后出去走一会儿，再回来写作业。

如果原来的流程已经足够牢固，新指令未必能覆盖它。孩子可能先做数学，再吃饭、休息和散步，到了晚上仍没完成语文作业。寄养家庭反复强调新的顺序，也不一定能改变这个行为：冲突的不是某一个动作，而是两套已经绑定在一起的流程。

模型也可能遇到同样的问题。训练开始大量加入特定 Agent 的流程数据后，模型优化的对象就不只是通用能力，还包括某套工具、提示词和运行时反馈。模型在熟悉的 Agent 中表现很好，换到工具结构不同的 Agent 后，反而可能更容易出错。

## 模型可能学到的不只是任务

以代码编辑为例，模型不仅要知道“修改这个文件”，还要决定：

- 使用什么工具；
- 参数采用什么字段名；
- 参数是扁平结构还是嵌套数组；
- 出错后是否等待重试，还是自行改写调用。

如果训练和强化过程长期围绕某一套工具格式展开，模型就可能形成强烈的工具调用先验。它学到的是一组稳定的行为模式，而不只是抽象的编辑能力。

Agent 场景中的“固定流程”可能包括工具参数格式、提示词结构、上下文组织方式，以及错误修复策略。它们的优先级和稳定性，可能高于调用者以为只是临时约定的几句提示词。


## Pi 的案例说明了什么

Pi 维护者 Armin Ronacher 在 [issue #6278](https://github.com/earendil-works/pi/issues/6278) 中记录了一个具体问题：部分新模型在 Pi 的 `edit` 工具上更容易生成错误调用。

Pi 的工具要求模型生成嵌套的 `edits[]` JSON；Claude Code 使用的 Edit 工具则更扁平，包含 `file_path`、`old_string` 和 `new_string` 等参数。Claude Code 还会处理参数别名、类型修正、未知字段过滤，并在失败后重试。

当模型看到名称相近的 Edit 工具，却遇到不同的参数结构时，可能带入另一套先验，生成 `oldText2`、`type`、`in_file` 等不属于当前 schema 的字段。

记录中的实验结果也支持“上下文和 harness 影响很大”这一判断：

- 复现某些历史上下文时，Opus 4.8 的工具调用失败率约为 20%；
- 去除历史中的 thinking block 后，失败率降到约 8%；
- 使用严格 JSON 或 tool schema 后，测试中的失败率降到 0%；
- 单轮简单编辑通常不会触发问题。

这些结果不能证明模型被写入了 Claude Code 的私有提示词，也不能证明 Anthropic 刻意让第三方 Agent 变差。它们更直接地说明：工具 schema、历史上下文、thinking block、自动修复和重试机制，会共同改变模型的实际行为。

## “模型针对 Claude Code 优化”应如何理解

“模型更适应 Claude Code”是一个合理假设，但它的含义需要收窄。模型可能学到的是：

- 某类工具的字段命名和参数形状；
- 某种 system prompt 与工具描述的组合；
- 工具调用失败后的修正方式；
- Claude Code 对不规范输出的容错边界。

这和“模型把 Claude App 的私有内容训练进去”是两回事。前者可以通过工具调用日志、公开行为和对照实验推测；后者需要内部训练数据或明确证据，目前不能从工具调用异常直接推出。

同样，第三方 Agent 中的失败也不等于 Claude Code 中永远正确。Pi 原作者 badlogic 提到，Claude 模型在 Claude Code harness 中也可能出现较高的工具调用错误率。模型、工具和运行时共同构成了最终系统，不能只把结果归因于模型权重。

## 真正需要测试的是组合

评估 Agent 模型时，不能只测“模型能不能完成编辑”。至少要固定并记录以下变量：

1. system prompt 和工具描述；
2. 工具 schema 是否严格；
3. 历史消息是否包含 thinking block；
4. 上下文压缩方式；
5. 参数清洗、错误提示和自动重试；
6. 单轮任务与长上下文任务的区别。

对照实验应使用同一模型、同一任务集，只替换 harness 或工具 schema。这样才能区分三类问题：模型能力下降、调用格式先验冲突，以及运行时缺少容错。

目前更可靠的结论是：新模型在某些第三方 Agent 中的工具调用确实可能变差；模型针对特定工具环境形成更强先验，是有实验现象支持的解释；“模型被故意训练成让第三方 Agent 失效”则没有足够证据。
