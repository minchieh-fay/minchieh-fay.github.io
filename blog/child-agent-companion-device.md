教育棒是一款面向儿童的独立手持 Agent 硬件，不依赖手机或平板，主要通过语音完成交互。孩子可以随时提出问题、表达想法，并得到适合自己的回应。

教育棒要解决的起点不是给孩子增加一个 AI 玩具，而是现实中家长陪伴能力的几个缺口。

## 家长陪伴中的缺口

### 知识支持不稳定

很多家长，尤其是工作日照顾孩子的爷爷奶奶，无法覆盖孩子不断扩大的问题范围。孩子问到科学、历史或数学中的复杂问题时，家长可能只能说“以后再告诉你”，问题也就此中断。

### 故事和想象依赖现成材料

孩子说“给我讲个故事”时，家长脱离绘本和熟悉的故事材料后，很难持续编出有情节、有细节、适合孩子年龄的内容。结果通常是重复几个故事，或者直接把手机交给孩子。

### 教育反应容易被情绪左右

家长不一定能稳定区分鼓励、表扬和批评的使用场景。疲惫、焦虑或生气时，教育反应会随情绪变化：孩子做对了可能没有得到具体反馈，做错了可能遭到过度批评；有些行为虽然暂时没有造成经济损失，却会让别人受影响，家长却在旁边发笑，孩子就可能把这种行为理解成“能让爸爸妈妈开心”。

### 家长看不到完整的日常

家长无法知道孩子在学校具体经历了什么，也不可能时时刻刻在孩子身边。放学后的询问往往只能得到零散回答，习惯、情绪变化和学习困难容易被错过。

## 教育棒的对应方案

教育棒把这些缺口转化为四类能力：知识与故事陪伴、稳定的沟通引导、日常记录和家长协同。它不替代家长做决定，而是在家长不在场或无法稳定回应时，先给孩子一个持续、可控的对话对象。

这个产品同时承担三种角色：

- 伙伴：记得孩子的经历、兴趣和沟通习惯，能持续对话。
- 老师：拥有足够的知识，负责解释问题、引导思考和帮助复习。
- 宠物：保持温和、稳定的性格，让孩子愿意主动交流。

三种角色的共同点是“主动获取”，而不是“被动接受”。孩子有奇思妙想时，不必等父母有空；爷爷奶奶无法回答复杂问题时，设备可以补上知识支持。像“如何用两根木棍测量地球和太阳的距离”这类问题，设备需要把答案拆成孩子能理解的观察、实验和推理过程。

针对故事需求，Agent 可以根据孩子的年龄、兴趣和当天经历生成连续故事，也可以让孩子决定人物、地点和下一步情节。故事陪伴的价值不在于无限生成内容，而在于让孩子通过语言参与构建和表达，避免每次都回到屏幕内容消费。

针对教育中的情绪问题，Agent 应使用稳定的回应规则：孩子完成了具体努力时给予鼓励，达到明确目标时给予表扬，出现伤害他人或违反约定的行为时指出影响并要求修正。它需要解释“为什么要改”，不能只说“你真棒”或“你怎么又这样”。家长可以在控制端调整规则，但不能把自己的即时情绪直接转发给孩子。

## 为什么不能只是一个手机 Agent

手机和平板的主要问题不只是屏幕。孩子拿到手机后，容易进入碎片化、强刺激的内容流，也可能直接要求通用 Agent 代写作业。这样的交互降低了主动思考的成本，也让家长难以控制使用边界。

独立硬件可以把能力限制在明确范围内：没有信息流，没有开放应用，没有默认屏幕入口，核心交互是听和说。设备不应该成为另一个娱乐终端，而应成为一个可被家长配置的儿童交互工具。

## 随时联系家长

设备上应有一个实体通话按钮。孩子按下按钮后，可以直接和家长通话，不需要像智能手表那样经过多层屏幕操作。设备也支持语音发起代传消息：

> 帮我跟我妈妈说一下，我晚上晚点回家。

对于“晚点回家”这类涉及安全和行程的信息，家长可以直接收到孩子的原话并回拨或回复。通话和代传消息都支持家长预先设置联系人，孩子不需要操作复杂的屏幕菜单。

这项能力直观地说明了教育棒的价值：它不是把家长从孩子的生活中移除，而是让孩子在需要时更快找到家长，让 Agent 负责日常陪伴和整理，把真正需要亲自沟通的事情及时交还给家长。

## 家长端是产品的一半

儿童端负责陪伴和提醒，家长端负责设置规则、安排任务和了解孩子的日常。

### 使用时间

家长可以配置工作日的禁用时段，例如 `08:00-17:00`，避免孩子在上课时使用。

### 学习复习

高级服务可以记录白天的课堂内容。孩子放学后，Agent 根据当天课堂内容发起复习对话，询问关键概念，发现没有掌握的部分，再用适合孩子的方式解释。

家长可以查看、删除和导出这些学习记录，也可以决定是否使用课堂复习功能。

### 交互规则

家长可以为孩子配置学习规则。例如：

> 所有数学问题不能直接讲答案，只能给出下一步提示；孩子连续尝试后，才逐步增加提示。

这比简单地切换“学习模式”更有效。Agent 会根据孩子已经尝试过的步骤继续提示，避免重复提示，也避免在孩子没有思考时直接完成作业。

设备第一期没有视频能力。孩子遇到问题时，需要先把问题描述清楚，包括正在做什么、已知条件是什么、卡在哪一步，以及希望得到哪类帮助。只说“这道题不会”时，Agent 会引导孩子补充信息，而不是直接猜测题目。

这看上去增加了使用成本，却也构成了产品的训练方式。孩子需要学习把一个问题拆成简单、完整、没有关键信息遗漏的表达，再和 Agent 一起定位困难、选择下一步。未来的学习和工作都要求较强的逻辑能力，清楚表达问题本身就是解决问题的一部分。Agent 会提醒孩子补充“题目是什么”“我已经试了什么”“哪一步不理解”等信息，让表达能力在真实任务中形成。

### 性格与沟通

家长可以补充孩子的沟通背景，例如“孩子比较懦弱，沟通中多鼓励”，或者“孩子经常捣蛋，沟通中提醒他考虑别人”。这些信息只能影响表达方式，不能让 Agent 给孩子贴固定标签，更不能把一次行为永久解释成性格。

Agent 的回应应包含具体反馈：肯定已经完成的部分，指出可调整的行为，提供下一步选择。鼓励不能替代事实，也不能用夸张表扬掩盖问题。

### 禁用领域

家长可以配置不讨论的领域，例如性相关内容、化妆相关内容。遇到禁用领域时，Agent 应简短拒绝并转向安全话题；不能通过隐喻、追问或推荐链接绕过限制。

### 孩子的个人提醒

孩子也可以直接管理自己的提醒，不必每次都通过家长端操作。例如：

> 给我定个闹钟，每周一早上八点。

> 给我列出现在的所有闹钟配置。

> 删除第三个闹钟。

Agent 会先复述提醒内容，再创建或删除配置。“第三个闹钟”对应当前提醒列表中的第三项，删除前会再次确认，避免误删。

孩子创建的提醒属于个人数据，家长端可以在授权范围内查看和管理，但展示应区分孩子自己设置的提醒与家长布置的任务。

### 家长任务编排

家长可以一次性布置一组带时间的任务，例如：

> 周日早上九点提醒他学英语，十点开始做数学作业，十一点半提醒午饭。

系统会把这段话列成独立任务，展示时间、任务内容、重复周期和执行状态。家长确认后，孩子就能按计划收到提醒。

每个任务可以勾选“检查”。开启后，设备在任务时间附近进行有限次数的随机询问，例如：

> 你现在在做哪一道题？题目叫什么？

问题应与任务有关，但不能要求孩子持续回应。孩子答不上来时，报告标记为“本次核验未完成”，不能直接等同于没有学习。

晚上，Agent 可以向家长发送当天任务报告，列出任务完成情况、孩子的回应和未确定项。报告使用“已确认”“未回应”“无法判断”等状态，不输出带有惩罚意味的结论。家长可以查看相关对话，并关闭某类任务的检查。

## 它还是家长了解孩子的桥梁

家长可以查看最近一周的对话主题、生活经历和反复出现的习惯。家长也可以在控制端询问：

> 下周孩子要过生日了，最近他最喜欢什么？适合准备什么礼物？

报告会区分“孩子明确说过的内容”和“Agent 的推测”。涉及情绪、健康、家庭关系的内容不会被当作确定判断。家长也可以删除记录或关闭长期记忆。

## 产品价值

教育棒面向的是一个普遍的家庭场景：家长愿意陪伴孩子，却无法随时提供知识、故事、情绪引导、学习监督和及时沟通。

它是一件轻量、易握、没有复杂屏幕的手持设备，孩子可以通过语音提问、听故事、管理提醒、完成学习任务，也可以一键联系家长。家长则可以设置使用规则、安排日程、了解孩子的日常，并在真正需要时介入。

教育棒最终要解决的不是家长没有时间陪孩子，而是孩子缺少一个稳定、可控制、能引导他继续思考的对话对象。它可以记住孩子，但记忆受家长控制；它可以教孩子，但不替孩子完成思考；它可以影响学习、性格和习惯，但不把孩子简化成一组标签。
